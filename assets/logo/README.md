# RGPS logo variants

These four PNG assets are crops of the official identity sheet supplied for this project:

- `rgps-primary.png` — primary logo, used as an About page feature.
- `rgps-horizontal.png` — horizontal logo, used in the footer.
- `rgps-emblem.png` — emblem-only logo, used in navigation and as the favicon.
- `rgps-monochrome.png` — monochrome logo, used on the Contact page.

All variants retain their white background from the identity sheet. Keep the clear space and proportions when using these marks.
